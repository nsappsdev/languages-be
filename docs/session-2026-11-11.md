# Session notes — 10–11 November 2026

## Delivered behavior

Each sentence can now have its own recording, alongside the existing standalone vocabulary recordings. Admin reviews the sentence breaks, prepares missing recordings, previews individual sentences, and can regenerate one sentence. Full-text listening uses one narration assembled from those sentence recordings. Practice still plays an unknown word naturally in context before its extra vocabulary repetitions; Deep Learning adds the configured sentence replays.

The mobile changes in this session keep Armenian translations on one line above their English words, start the translation pulse on the first natural reading, and display the reading-mode names saved by admin. The admin appearance form now accepts font saves after unrelated mode-setting changes without reporting a false version conflict.

## Backend changes

- Added `AudioAssetKind.SENTENCE` and `SentenceAudio`, with a unique text/request identity, job ownership, saved alignment and retry state.
- Split saved text into sentence spans while retaining source offsets. Reviewed boundaries must cover the complete text in order, stay between words, preserve Unicode characters and avoid splitting selected vocabulary phrases.
- Generate sentences sequentially with neighboring text supplied as ElevenLabs context. Persist every successful recording before requesting the next one.
- Reuse recordings only when text, voice, neighboring context, model, output format and synthesis-settings version match. Explicit regeneration replaces the selected sentence's cache entry; older assets remain available to published snapshots.
- Assemble exact PCM samples and rebase the provider's real character timestamps onto the combined timeline. Missing or invalid alignment retains the existing review/publication protections.
- Preserve vocabulary selections, Armenian translations and recording associations when regenerating audio for the same content revision and successfully aligned ranges.
- Retain completed clips after failures. Uncertain provider outcomes and expired in-flight jobs require review and explicit regeneration rather than an automatic potentially chargeable request.
- Return sentence recordings, planned boundaries and the latest narration job to admin. New publications carry optional `narrationSource: "SENTENCES"` and the complete recorded sentence bounds; older schema-version-2 publications remain compatible.

# Sentence-first authoring — 2026-11-14

Saving source text creates its word/phrase map immediately. Selection and translation import do not depend on narration or speech timing. Vocabulary audio is extracted from each occurrence's own sentence after its recording and timing are ready; it makes no speech-provider request. Imports remain atomic for the valid, source-matched entries submitted by the admin preview; the frontend reports and omits unmatched or untranslated input rows. The 500-entry API cap is removed.

Sentence breaks can be saved independently with `PUT /admin/lessons/:lessonId/texts/:textId/sentences`. Generation accepts `sentenceIndex` for a first recording, `regenerateSentenceIndex` for an explicit replacement, or neither to fill all missing sentence recordings. Matching recordings are reused, uncertain requests require explicit regeneration, and failed timing is reported for the specific sentence. Selections and translations survive audio or sentence-plan changes on the same source revision. A split through a selected phrase is rejected.

New jobs create sentence assets and a virtual sample timeline, never a whole-text NARRATION asset. `TextNarration.assetId` is null for these metadata records. `TextAlignment.narrationId` may be null for a text-only map. Apply migration `20261114090000_sentence_first_authoring` before starting the updated backend.

New sentence-only publications use manifest version 3: `narration` contains duration/sample-rate metadata with `kind: "sentences"`; every sentence carries its own authenticated immutable asset. Publication requires every sentence recording and reliable word timing, plus translated learning selections with prepared vocabulary clips. Each clip is an exact PCM slice of its source sentence, including a lead-in before the first consonant and bounded to that sentence. Repeated spellings retain occurrence-specific delivery. A new alignment invalidates draft clips; preparing them again uses the current recordings without TTS. Existing version 2 publications and previously queued legacy narration jobs remain supported. Deploy the updated mobile reader before enabling production publication of version 3 lessons; older installed mobile builds do not understand version 3.

Validation: backend build, 58 unit tests, and 52 integration tests pass against an isolated local PostgreSQL database with all 30 migrations. Tests cover imports before audio, 501 imported occurrences, individual first generation, saved split/join plans, phrase preservation, sentence timing failures, cache/retry behavior, immutable publication, and authenticated sentence downloads. Paid speech calls were replaced by a synthetic provider in tests. Local browser playback additionally used previously saved real speech, with zero external generation calls. No production migration or deployment performed.

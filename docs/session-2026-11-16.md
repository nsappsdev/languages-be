# Session record — 16 November 2026

This record continues [the earlier session notes](session-2026-11-11.md). It distinguishes changes already on main from the sentence-first work committed at the end of this session.

## New backend behavior

- Saving lesson text creates selectable word and phrase identities immediately. Admin can select vocabulary, save Armenian translations, and import matching entries before any audio exists.
- Sentence boundaries can be reviewed, split/joined, and saved independently of generation. Splitting through a selected phrase is rejected, and selections/translations survive changes to the sentence plan or recordings when the source revision is unchanged.
- Generate all missing sentence recordings or generate/regenerate an individual sentence. Matching recordings are reused; uncertain provider outcomes require explicit regeneration. Timing problems identify the affected sentence.
- New generation produces sentence assets and a virtual timeline. It does not create an entire-text audio file.
- Sentence-only publications use reader manifest version 3, with one immutable authenticated asset per sentence. Existing version 2 publications and queued legacy jobs remain supported.
- Word and phrase audio is extracted from the original sentence occurrence, preserving its voice and delivery. The extraction includes the consonant lead-in, stays within that sentence, and makes no new TTS request. Equal spellings in different contexts retain their own clips.
- Removed the arbitrary 500-entry import cap. The admin filters invalid input and reports skipped rows; the API validates and atomically imports the accepted text matches.

See [sentence-first authoring](sentence-first-authoring.md) for the API, publication rules, and migration details.
